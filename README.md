# 食衣住行育樂帳本

依「食、衣、住、行、育、樂」六大類記錄開銷，可以按月份查看總額和各類占比。資料會先存在手機或電腦本機，再同步到你自己的 Google Sheet。

- App：https://danll737321-beep.github.io/expense-tracker/
- 後端：`apps-script/Code.gs`

## 第一次設定（約 5 分鐘）

1. 新開一個 Google 試算表，名稱自取，例如「家庭帳本」。
2. 在試算表選單點「擴充功能 → Apps Script」，把預設的程式碼全部刪掉，貼上 `apps-script/Code.gs` 的內容，再按存檔。
3. 上方函式下拉選單選 `setup`，按「執行」。
   - 第一次執行會要求授權。如果出現「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」繼續；這是你自己寫的腳本，所以會有這個提示。
   - 執行完到「執行記錄」，複製「你的密鑰：」後面那一串。
4. 點右上「部署 → 新增部署作業」，齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」後，複製結尾是 `/exec` 的網址。
5. 打開 App，在最底下「雲端同步設定」貼上網址和密鑰，記錄人可以填自己的名字，然後按「儲存並同步」。
6. 其他裝置（太太的手機、你的電腦）重複第 5 步，網址和密鑰都一樣。

## 運作方式

- 記帳時會先存在本機，畫面立刻更新，接著在背景上傳。離線時記的帳會標「待上傳」，等連上網路就自動補傳。
- App 會在打開、切回前景、恢復網路，以及每 60 秒自動同步一次。
- 試算表的 `Expenses` 工作表是唯一正本，可以直接在上面做樞紐分析。
  - 如果要手動修改，請改金額、備註、日期這幾欄，**不要改 `id` 欄**。

## 安全性

- 部署設定的「所有人」，代表知道網址的人可以呼叫這個網頁應用程式，但沒有密鑰就讀不到、也寫不進任何資料。
- 密鑰存在 Script Properties 裡，不在程式碼中，所以這個 repo 可以公開。
- 懷疑密鑰外流時，在 Apps Script 執行 `resetToken`，再把新的密鑰貼到每台裝置。

## 之後修改 Code.gs

改完程式後，要到「部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本：新版本 → 部署」。這樣更新，網址會維持不變。
